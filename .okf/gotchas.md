# Gotchas

- **AOT discovery:** reflection `AddFastEndpoints()` is not supported under AOT. Use `AddFastEndpoints(DiscoveredTypes.All)` plus the Generator analyzer.
- **DiscoveredTypes skips open generics, including nested types:** a class nested inside `Outer<T>` is itself generic (`IsGenericType`). `AssemblyScanner` drops it, and `DiscoveredTypesGenerator` does too. Emitting `Outer<T>.Inner` does not compile. Move the type out of the open generic to register it.
- **Generator package shape:** output is `analyzers/dotnet/cs`. `DevelopmentDependency` is false on purpose. Reference it as an analyzer, not a normal library.
- **AccessControl categories:** only string literals and compile-time constants (`const`, `nameof`). Runtime expressions are ignored, so the permission gets no group. Mechanism: [generated-code.md](generated-code.md).
- **Serializer contexts:** do not hand-edit. Dev CLI must already be built under `Src/Generator.Cli/bin/.../net8.0/`. Index, cache `v2`, and props: [generated-code.md](generated-code.md).
- **Pinned packages:** do not casually bump `Microsoft.CodeAnalysis.CSharp` or `Microsoft.OpenApi.Kiota.Builder`. Why: [dependencies.md](dependencies.md).
- **Agents versioning:** `Src/Agents/Directory.Build.props` must `Import` the parent props. MSBuild stops at the first `Directory.Build.props`. Shared agent code is linked compile, not a NuGet.
- **Agents friend-assembly binary contract:** `InternalsVisibleTo` in `Src/Library/Metadata.cs` for `FastEndpoints.Mcp` and `FastEndpoints.A2A` (independent versions). Recompiling addons here does not prove published NuGets still load. Changing the name, arity, parameter types, or return type of a stocked internal can `MissingMethodException` shipped addons. Touch any of these in Library: check the agent packages and restock this list in the same change.
  - **Reflection / binding** (`BinderExtensions.cs`, `ReflectionExtensions.cs`): `Type.BindableProps()` (return type is part of the CLR signature), `PropertyInfo.FieldName()`, `Type.IsComplexType()`, `Type.IsCollection()`.
  - **Bootstrap / discovery** (`EndpointBootstrap.cs`, `EndpointData.cs`, `MainExtensions.cs`): `EndpointBootstrap.CreateEndpoint(HttpContext, EndpointDefinition)`, `EndpointData.Found`, `MainExtensions.BuildRoute(StringBuilder, int, string, string?)`. Do not add a `BuildRoute` parameter. `DontVersion()` is how version 0 omits the segment.
  - **EndpointDefinition fields:** `SerializerContext`, `Disposable`, `DisposableAsync`.
  - **Config / type tokens:** `Config.SerOpts` (also `using static FastEndpoints.Config`), and `Types` fields agents use: `EmptyRequest`, `FromBodyAttribute`, `ToHeaderAttribute`, `String`.
  - **Call sites to check when restocking:** `Src/Agents/Shared/` (`AgentRequestBuilder.cs`, `AgentJsonPropertyNames.cs`, `AgentHttpContextFactory.cs`, `EndpointInvoker.cs`, `AgentEndpointCatalog.cs`), `Src/Agents/Mcp/` (`McpToolSchemaFactory.cs`, `EndpointMcpToolSource.cs`), `Src/Agents/A2A/` (`A2AJsonRpcEndpoint.cs`, `A2ASkillDispatcher.cs`, `Extensions.cs`).
- **Non-flags enum binding rejects comma lists:** with `AllowUndefinedEnumValues` false (default), `BinderExtensions.ValueParser` rejects undefined numerics. Enums without `[Flags]` also reject comma-separated names and repeated values (`Monday,Tuesday`, `?day=Monday&day=Tuesday`), because `Enum.TryParse` bitwise-ORs them into another defined member. `[Flags]` lists still bind when the combination is defined. `true` restores raw `TryParse`. JSON bodies stay on STJ options.
- **Legacy vs modern OpenAPI:** harness uses `FastEndpoints.OpenApi` + Scalar. NSwag Swagger/ClientGen are Legacy. Their tests may be commented out of the slnx.
- **OpenAPI generation is per-request and concurrent:** do not cache or lock `GetOpenApiDocumentAsync`, and do not put operation/schema bags back on `SharedContext` (including via `AsyncLocal`). Bags live on `OpenApiGenerationState`, keyed by the `OpenApiDocument` (`ConditionalWeakTable`). A shared TestServer execution context lets `ResetPerDocumentState()` clear a sibling generation. Snapshot helpers take `Fixture.DocumentGenerationLock`.
- **OpenAPI form files:** normalize `IFormFile` and form-file collections to inline binary schemas, then remove generated `IFormFile*` components. Rewrite before removal or refs dangle.
- **OpenAPI schema `$ref` (Microsoft.OpenApi 2.x):** `OpenApiSchemaReference` often has null `Properties`/`Type` until `ResolveSchema()`. Pass `Components.Schemas` when `HostDocument` may be unset. Cycle sets key on the resolved schema.
- **OpenAPI `.http` bodies:** media-type `Example`, else first named `Examples`, else schema `Example`, else `Default`, else placeholders. A media-type example replaces the body wholly (no merge). Form is omitted. Non-JSON uses `{{body}}`.
- **OpenAPI conditional validation:** FluentValidation `NotNull`/`NotEmpty` under a condition must not emit unconditional `required`, non-null, or min-length. Unconditional presence rules still apply. The same mapping covers DTO-bound query/path/header/cookie parameters, not only bodies. Flattened `[FromQuery]` objects are not matched to nested validator paths.
- **CI filter and Kiota skip:** [testing.md](testing.md). `ExcludeInCiCd` tests are not a merge gate. MTP ignores `IsTestProject`. Exit 8 means zero tests ran, not a failed assertion.
- **NuGet push must `--skip-duplicate`:** Agents are packed from `FastEndpoints.slnx` on their own version line. A core-only tag re-pushes the last Agents version. nuget.org 409s and `dotnet nuget push` stops, so later packages in the glob never publish. Do not bump Agents versions just to make a core release succeed.
- **WAF cache:** one cached factory per `AppFixture` type. Static state on that factory leaks across tests. Register doubles in `ConfigureServices`. Teardown hook: [testing.md](testing.md).
- **Test url cache route is opt-in:** `EndpointRouteMapper` maps anonymous `_test_url_cache_` (every route and endpoint type name) only when `IConfiguration["FastEndpoints:ExposeTestUrlCache"]` is `true`. Do not map it unconditionally or gate it on environment name. In-process WAF uses the always-on `IEndpoint.SetTestUrl` cache. Out-of-process routeless helpers fall back to the route (`HttpClientExtensions.GetTestUrlFor` when `IEndpoint.TestURLFor` misses). `AppFixture.Aot` sets `FastEndpoints__ExposeTestUrlCache=true`.
- **Routeless test URL encoding:** `GetTestUrlFor()` encodes matched route values with `Uri.EscapeDataString`. Unmatched placeholders stay intact. Query values use `WebUtility.UrlEncode`. Do not use query encoding for path segments (`+` is not a path-space escape).
- **JWT revocation checks the accepted token:** `JwtRevocationMiddleware` checks the `Authorization` header, then the `access_token` saved on each `JwtBearerHandler` scheme's cached `AuthenticateAsync` result. That second check needs `JwtBearerOptions.SaveToken` (`AddAuthenticationJwtBearer` defaults it to `true`). Unmatched endpoints are still checked. Only `IAllowAnonymous` skips. Do not revert to header-only, and do not treat a null endpoint as anonymous.
- **Mappers are singletons:** no request state in mapper classes.
- **`ServiceResolver.CreateSingleton` uses the host root provider:** validators, mappers, processors, binders, feature flags, event handlers, and command executors are created lazily, often inside a request. Resolve the host's `IServiceResolver` singleton from `RequestServices` and build from that root. Never build from `RequestServices`, and never from the captured `provider` during a request (multi-host tests can hold a disposed host). `Factory.AddTestServices` is the only exception, because its root provider is empty.
- **Signing / InternalsVisibleTo:** use the full public key from props. Unsigned local builds break friend assemblies, including the agent packages above.
- **User DotSettings:** `*.sln.DotSettings.user` is personal. Not repo policy.
- **Do not commit secrets:** NuGet keys, or real JWT signing material.
- **Generated harness folders:** NativeAotChecker `Generated/`, `wwwroot/openapi/`, and `aot/` are build outputs. Regenerate. Do not hand-maintain. Details: [generated-code.md](generated-code.md).
- **Version citation:** read `Src/Directory.Build.props`. Do not copy the package version into OKF.
- **Docs live outside this repo:** `../FE-Docs/src/content/docs/` ([workflows.md](workflows.md)).
- **Event hub statics leak across tests:** `EventHub<,,>` assigns `EventHubStorage<TStorageRecord,TStorageProvider>.Provider`. A second in-process handler server on the default in-memory storage types clobbers `Sut` and fails unrelated tests. Test the marshaller or binder directly, or use storage types unique to that test.
- **`UseFastEndpoints()` unit tests must restore process statics:** that call sets `ServiceResolver.Instance`. Disposing the `WebApplication` without a reset makes later `Factory.AddTestServices` hit `ObjectDisposedException`. Also save and restore `Config.EpOpts` (Filter, RoutePrefix, Configurator) and `MainExtensions.SerializerConfigured`. Pattern: `[Collection(RouteMapperCollection.Name)]` plus `IDisposable`, as in `EndpointRouteMapperTests`. A collection only serializes tests inside it. Other classes that mutate the same statics (`RoutePrefixTests`, `WarmupTests`, `FinancialIdempotencyMapperTests`) must join that collection.
- **Test receivers are append-only spies.** Match rules and capture timing: [testing.md](testing.md).
- **RPC wire format is per-connection and set-once:** set `RemoteConnection.MarshallerFactory` before any `Register<>()` (registration captures it and throws otherwise). Server and client must match. Both take the bound gRPC method name from the factory (MessagePack `""`, protobuf `Execute`). The default comes from DI, so `AddHandlerServer(marshaller:)` also becomes the default outbound factory in a process that is both server and client. Set it per connection when the peer uses a different format.
- **Reflection needs protobuf:** `MapHandlerReflection()` throws at startup unless `AddHandlerServer(marshaller: new ProtobufMarshallerFactory())` is set. `AddHandlerReflection()` only registers services. MessagePack has no descriptors. Attribute-free field numbers are positional, so adding or renaming a property renumbers the rest. Pin with `[ProtoContract]` / `[ProtoMember(n)]` when the contract must survive edits.
- **Reflection describes less than it serializes:** the descriptor generator skips `DateTime`, `DateOnly`, `TimeOnly`, `TimeSpan`, `decimal`, `Guid`, `Uri`, dictionaries, and nested commands (`CommandNotDescribable`). Those handlers still run via protobuf-net. Only field numbering is shared with the marshaller. `IsMessage(KeyValuePair<,>)` stays false so map entries are not published as empty messages.
- **Protobuf BCL denylist:** `ProtobufMarshallerFactory.IsMessage` / `IsNonMessageType` keep BCL specials out of attribute-free `Model.Add` (hollow contracts corrupt the wire). Edit that denylist together with the descriptor tests. Do not copy the type list into OKF.
- **Financial HTTP idempotency is not output cache.** It needs a trusted stable `CallerScope`. `AdditionalHeaders` defaults empty. Stores return immediate `InFlight` (`409`). Settlement is ownership-token CAS. Active and uncertain reservations never auto-expire. Completed retention starts at completion. A second `AddFinancialIdempotency()` throws.
- **Financial abandon vs retain:** only `RejectFinancialIdempotencyWithoutSideEffects` releases a key. `FeRequestHandler` uses it for its pre-endpoint `415` and hit-counter `403`/`429`. Exceptions, cancellation during the handler, ambiguous non-2xx, and endpoint validation failures retain the key. A finished 2xx completes even if the client already aborted. `Started` without a token, or `Replay` without a response, fails closed and does not run the handler.
- **Financial `PipelineKey` is per request.** `ExecAsync` requires `FinancialIdempotencyMiddleware.PipelineKey` for that invocation, including direct callers such as agent invocation. The middleware sets it only around the reserved `next()` and clears it in `finally`.
- **Financial identity and hash ownership:** `FinancialIdempotencyOptions` owns the header cache (`ApplyDefaults` rebuilds it; `IdentityHeaders` does not cache before mapping). `IdentityHeaderNames` only normalizes names. `FinancialPayloadHash.ComputeAsync` owns buffering, rewind, and position restore in one `try/finally`, and clears the rented hash buffer. `SnapshotHeaders` copies stored headers. Middleware owns snapshot timing and replay. Snapshot exclusions are stricter than replay filtering and must not filter the first response.
- **Financial identity bytes are a persistence contract** (version-1 payload includes media type and declared charset). PathBase is included. One trailing slash is normalized (empty root becomes `/`). Repeated or internal slashes and the case option stay. Only RFC 3986 default ports are stripped. Changing these identities after release requires migration or draining reservations, never a mixed-version rollout.
- **Financial memory store:** expire a completed key on that key's `TryBegin`. `Reclaim` full-scans only when admitting at `maxEntries` or on complete. Capture includes empty 204 and pending pipe bytes. Overflow fails closed. File contents are hashed. Process restart drops protection. Durable reconciliation and downstream business idempotency stay app-owned.
- **Job queue idempotency:** `IdempotencyKeyFor<TCommand>` requires storage record `IHasIdempotencyKey` (checked at `UseJobQueues`). Uniqueness is `(QueueID, IdempotencyKey)` until the row is purged, including completed rows. Providers throw `DuplicateJobException` with the existing `TrackingID`. The library does not catch raw DB unique violations. Null, empty, or whitespace selector results skip dedupe.
- **`HandleValidationFailure` stays a private method** on `Endpoint.cs`, taking `req`, `ranPreProcessors`, and `ct`. Do not make it an async local inside `ExecAsync` (the closure allocates on every request, including successes). Do not name it `ValidationFailed` (public property on `Endpoint.Validation.cs`).
- **`EventBus<TEvent>._handlers` stays `IEventHandler<TEvent>[]`.** `Execute` uses `Length`, indexing, and a single-handler fast path. Do not widen the field to `IEnumerable<>`. Do not inline `Offload`, `OffloadOne`, `OffloadAll`, or `Filter` into `Execute` (the display class then allocates on every publish, including single-handler `WaitForAll`). Single-handler `WaitForAny` still goes through `Task.WhenAny`, not the raw `Task.Run` task, so handler faults stay uncaptured per `Mode`.
- **`ResponseCacheExecutor` caches `Cache-Control` once per endpoint.** That is valid only because `ResponseCache(...)` is `ThrowIfLocked()`. A runtime mutation of location or duration must invalidate the cached string.
- **`EndpointRouteMapper` locks and clears after the route loop.** `def.AttribsToForward = null` and `def.IsLocked = true` stay after `foreach (var route in def.Routes)`, not inside it. Indentation is already dedented. Check the braces. Inside the loop, attribute-configured multi-route endpoints forward metadata and lock on route 1 only. `AttribsToForward` is filled only on the attribute path (`EndpointExtensions.Initialize`).
- **`DontVersion()` vs `Version(0)`:** `Version(0)` is still unset. `EpVersion.Init()` then applies `DefaultVersion`. `DontVersion()` keeps version 0 and omits the route segment. Do not use `-1` or any negative sentinel. OpenAPI release-group filtering is `version >= MinEndpointVersion && version <= MaxEndpointVersion`, and `Current` is public metadata.
- **`Void` stays a zero-field struct with `Instance = default`** (`Src/Messaging/Messaging.Core/Interfaces/ICommand.cs`). `AsyncTaskMethodBuilder<TResult>` reuses its cached `Task<TResult>` only when the result equals `default(TResult)`. A class, or any field, brings back a `Task<Void>` allocation on every synchronously completing send, with no compile error. `Void` is public: audit `where TResult : class` on `ICommand<TResult>` and `IServerStreamCommand<TResult>` before changing it. Not `Types.Void` in `Src/Library/Types.cs` (`typeof(void)`).
- **JobQueue is not an open-generic DI service.** `UseJobQueues` builds each `JobQueue<TCommand,TResult,...>` with `ActivatorUtilities.CreateInstance` and stores it on `JobQueueBase.JobQueues`. Do not `AddSingleton(typeof(JobQueue<,,,>))` and resolve it. Native AOT refuses to close that open generic over `Void`. Void commands use internal `JobQueueVoidResult` (a class), not `Void`. `ExecuteCommand` already handles `ICommand` before `ICommand<TResult>`. `IJobTracker<>` stays open-generic because `TCommand` is a class.
- **Void command executors are not `CommandHandlerExecutor<TCommand, Void>`.** Native AOT cannot emit that closed valuetype. `PrepareExecution` uses `VoidCommandHandlerExecutor<TCommand>` when `TResult` is `Void`. Middleware types come from `CommandMiddlewareRegistrations` (`AddCommandMiddleware`), not `GetServices<IEnumerable<ICommandMiddleware<TCommand, Void>>>`. Do not swallow `NotSupportedException` into an empty pipeline. Under AOT, register with closed `Register<TCommand, Void, TMiddleware>()`. Open `Register(typeof(Foo<,>))` throws for void commands when dynamic code is unavailable.
- **Handler short-circuit is opt-in.** Pre-processors skip the handler when `ResponseStarted` is true. `OnBeforeHandle*` does not, unless `DontExecuteHandlerIfResponseStarted()` set `SkipHandlerIfResponseStarted`. That early return also skips `OnAfterHandle*`. Post-processors still run.
- **`CommandExtensions.ExecuteAsync` computes the handler interface lazily.** `MakeGenericType` for `ICommandHandler<>`, `ICommandHandler<,>`, and `IStreamCommandHandler<,>` stays inside `HandlerInterfaceType`. `PrepareExecution` calls it only on first generic dispatch (`InitGenericHandlerCore`) or the `TestCommandHandlerMarker` branch. Do not hoist it to the top of `ExecuteAsync`. Void test handlers are `ICommandHandler<TCommand>` (Of1), not `ICommandHandler<TCommand, Void>` (Of2). Keep the `tHandlerOf1 is not null && tRes == Types.VoidResult` check.
